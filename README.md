# 经营主体有序退出

本项目服务于处理长期未经营主体的退出、异议和恢复程序。仓库保存领域资料、交换契约和可运行的服务入口，便于参与方在同一语义下协作。

## 领域事实

- 监管部门将畅通长期未经营主体退出渠道
- 改革兼顾降低制度成本与有序退出
- 市场治理强调有进有出

## 领域模型

### 程序时间线

每个退出案件维护一条只增不改的程序时间线，由以下事件组成：年报、经营迹象、联系记录、税务社保状态、债权申报、司法限制、公告、异议、部门回执、通知、清算证据、举报与程序转移。案件状态由事件推导，最终退出结论可由全部事件重新构建（`GET /cases/:id/conclusion/verify`）。

### 程序与转移条件

四类程序共用一台状态机，转移条件集中在 `src/domain/procedures.js`：

- **主动注销（普通程序）**：受理 → 审查 → 公告中（债权人公告）→ 决定 → 已退出。进入决定须公告届满、无异议、无司法限制、无未核销风险标记且已提交清算报告。
- **简易退出**：公告期更短，但要求无未了结债权、无欠税欠薪、无司法限制。公告期内异议成立即转入普通程序并重新公告；异议不成立则恢复公告（暂停期间不计入）。
- **强制退出**：监管部门对长期未经营主体发起。启动公告须满足版本规定的未年报次数、登记住所失联、税务异常，且无经营迹象、无欠税欠薪、无未了结债权、无司法限制。异议成立即终止；主体现身可转主动注销。
- **歇业**：受理 → 歇业中 → 已恢复；歇业中也可转主动注销。

转移条件不满足时，服务返回具体中文理由，申请人与利害关系人看到的期限与理由完全一致。

### 适用法律版本

主体类型与适用法律按**申请时**有效的版本判断：立案时锁定版本快照（公告天数、强制退出门槛、主体类型目录），后续修订不影响在办案件。版本库见 `src/domain/law-versions.js`（示例配置，可由主管部门维护）。

### 公告期暂停

公告期自发布次日起算。以下情形暂停计时（`src/domain/announcement.js`）：

- 法定节假日（节假日历按年度注入）；
- 补正期间（登记补正即暂停，并自动发出补正通知）；
- 诉讼保全期间（登记司法限制事件时自动暂停，解除时自动恢复）；
- 异议审查期间（异议提出即暂停）。

暂停含起止日；重叠区间只扣除一次；暂停未结束时届满日待定，恢复后重新确定。

### 部门回执

部门回执可迟到但不能倒退案件：回执按签发阶段登记，晚于案件当前阶段的标记 `late`，案件阶段保持不变。负面回执（如发现欠税）转为风险标记，阻断后续决定，须经办核销后方可继续。

### 债权申报

同一债权人基于同一债权依据的重复申报登记为重复件，不多占金额；原始件撤回后重复件不自动转有效，须经办核实。

### 角色与可见性

角色：申请人、利害关系人、经办人、审计人员。敏感举报仅经办角色可见；期限与理由由各角色共享同一时钟与同一守卫求值，保证一致。

## 目录说明

- `contracts/` 保存交换数据的结构约定（领域上下文、程序时间线事件）。
- `fixtures/` 提供去标识的领域样例。
- `src/domain/` 领域规则：日期、法律版本、节假日、公告期时钟、债权、程序状态机、访问控制、案件聚合、结论构建。
- `src/service.js` 案件存储与命令/查询入口；`src/server.js` HTTP 接口。
- `test/` 核对领域资料与全部领域规则。

## 本地检查

运行 `npm test` 可以检查当前资料与服务入口。

## 服务接口

`node src/server.js` 启动于 `http://127.0.0.1:8000`。角色通过 `?role=` 或 `x-role` 头传入（默认申请人）。

- `GET /health`、`GET /context`：健康检查与领域资料。
- `POST /cases`：立案（`entityType`、`procedure`、`appliedAt`、`applicant`）。
- `GET /cases/:id?role=&asOf=`：案件视图（阶段、期限、理由、时间线）。
- `POST /cases/:id/events`：登记时间线事实（`category` + 载荷）。
- `POST /cases/:id/claims`、`POST /cases/:id/claims/:claimId/withdraw`：债权申报与撤回。
- `POST /cases/:id/objections`、`POST /cases/:id/objections/:id/ruling`：异议与裁定。
- `POST /cases/:id/receipts`：部门回执。
- `POST /cases/:id/announcement/pause|resume`：公告暂停与恢复。
- `POST /cases/:id/transitions`：程序/阶段转移（`target`）。
- `POST /cases/:id/risk-flags/:id/clear`：核销风险标记。
- `GET /cases/:id/conclusion`、`GET /cases/:id/conclusion/verify`：退出结论与可重建性校验。
